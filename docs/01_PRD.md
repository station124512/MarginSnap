# [PRD] 초보 셀러를 위한 스마트 마진 계산기 (Smart Margin Calculator)

- **문서 버전**: v1.0.0
- **작성일자**: 2026-10-24
- **상태**: 승인 대기 (Draft)
- **작성자**: 기획팀
- **타겟 플랫폼**: Web (Mobile-First Responsive Web)

---

## 1. 프로젝트 개요 (Executive Summary)

### 1.1 기획 배경
온라인 이커머스(쿠팡, 스마트스토어 등)에 진입하는 초보 셀러 수가 매년 급증하고 있으나, 복잡한 플랫폼별 수수료 체계, 숨겨진 원가(포장비, 반품 충당금, 부가세, 광고비 등)의 누락으로 인해 **"물건은 팔리는데 통장 잔고는 마이너스"가 되는 역마진(Negative Margin) 사태**가 빈번하게 발생하고 있습니다.

초보 셀러의 대다수는 복잡한 엑셀 수식을 다루는 데 어려움을 겪으며, 플랫폼마다 제각각인 수수료율(판매수수료, 결제수수료, 배송비 수수료, 부가세 별도 부과 등)을 정확히 인지하지 못합니다.

### 1.2 제품 비전
> **"단 1분 만에 끝내는 역마진 제로(0%) 마진 검증기"**  
> 초보 셀러가 몇 가지 핵심 수치만 입력하면, 숨은 비용까지 완벽히 계산하여 **진짜 통장에 꽂히는 순수익**을 보여주고, 목표 마진을 얻기 위한 **최적 판매가를 역산**해주는 스마트 솔루션.

## 2. 타겟 사용자 분석 (Target Audience & Persona)

### 2.1 주요 사용자 페르소나

| 구분 | 페르소나 A (위탁/사입 입문 셀러) | 페르소나 B (쿠팡 로켓그로스 진입 셀러) |
| :--- | :--- | :--- |
| **이름/나이** | 김민우 (31세, 직장인 부업 셀러) | 박지현 (28세, 전업 온라인 셀러 2개월차) |
| **주요 채널** | 스마트스토어, 쿠팡 윙(판매자 배송) | 쿠팡 로켓그로스(제트배송) |
| **주요 고민** | 엑셀 템플릿을 구했는데 수식이 깨지고, 배송비 수수료와 부가세를 어떻게 빼야 할지 모름. | 입고비, 보관료, 입출고 배송비 등 그로스 부대비용이 복잡해 역마진이 불안함. |
| **핵심 니즈** | 직관적으로 입력하고, "얼마에 팔아야 내가 20% 마진을 남길 수 있는지" 역산 원함. | 광고비(ROAS)와 플랫폼 부대비용을 뺀 실정산액을 한눈에 그래프로 보고 싶음. |

### 2.2 사용자 페인 포인트 (Pain Points)
1. **숨은 비용 누락**: 부가세(10%), 포장박스/테이프/완충재 비용, 반품률에 따른 손실비용을 누락하여 장부상 흑자, 실제 통장 적자 발생.
2. **복잡한 플랫폼 수수료**:
   - 쿠팡: 카테고리 수수료(최대 10.8% + 부가세 10% = 약 11.88%) + 배송비 수수료(3.3%)
   - 네이버: 주문관리수수료 + 매출연동수수료(카테고리 무관 고정 or 연동몰 차등)
3. **목표 판매가 산정 불가**: 원하는 순이익(예: 개당 5,000원)을 얻으려면 최종 판매가를 얼마로 책정해야 하는지 역산 공식이 어려움.
4. **광고 집행 시 마진 변동**: 광고 ROAS가 몇 % 밑으로 떨어지면 적자가 나는지 기준(BEP ROAS)을 모름.

## 3. 핵심 제품 목표 (Product Goals & KPIs)

1. **역마진 제로화**: 입력 즉시 손실 여부를 판별하여 시각적 경고(Red Alert) 제공
2. **입력 시간 단축**: 플랫폼/카테고리 프리셋을 통해 기본 정보 3단계(판매가, 원가, 배송비) 입력만으로 10초 내 1차 결과 도출
3. **완전한 비용 투명성**: 매출액 대비 원가, 수수료, 물류비, 광고비, 예상 세금의 비중을 인터랙티브 차트로 시각화
4. **목표 마진 역산(Reverse Calculation)**: 목표 마진율(%) 또는 목표 순이익(원)을 입력하면 권장 판매가를 즉시 산출

### 성공 지표 (KPIs)
- **계산 완료 전환율**: 진입 세션 대비 1회 이상 계산 완료율 ≥ 85%
- **역산 기능 활용률**: 전체 사용자 중 목표 마진 역산 탭 이용률 ≥ 40%
- **재방문율 (Retention)**: 주간 재방문율(Wau Retention) ≥ 35%
- **계산 결과 저장/내보내기 수**: 세션당 결과 저장/클립보드 복사 건수

### 4.2 상세 기능 명세 (Detailed Features)

#### [Feature 1] 판매 채널 프리셋 & 수수료 자동 매핑
- **플랫폼 선택**:
  - `쿠팡 윙 (마켓플레이스)`: 카테고리별 수수료(4% ~ 10.8% + 부가세 10% 별도) + 배송비 수수료 3.3% 자동 반영
  - `쿠팡 로켓그로스 (제트배송)`: 판매수수료 + 물류입고/보관/출고 배송비 요금 체계 템플릿 제공
  - `네이버 스마트스토어`: 네이버페이 결제수수료(등급별 1.98%~3.63%) + 매출연동수수료 2%
  - `직접 입력 (커스텀)`: 기타 오픈마켓(11번가, G마켓 등)용 수수료율 수동 세팅
- **카테고리 선택 드롭다운**: 패션의류, 식품, 가전, 뷰티, 생활용품 등 주요 카테고리 선택 시 수수료율 자동 입력
- **배송비 수수료 자동 토글**: 플랫폼별 배송비에도 수수료가 부과되는 정책 자동 적용

#### [Feature 2] 초보 친화적 원가 & 지출 입력 폼
- **기본 입력 (필수)**:
  - 판매가 (원)
  - 상품 사입/제조 원가 (원)
  - 고객 부담 배송비 (무료배송 시 0원)
  - 판매자 실 지출 배송비 (원)
- **상세/고급 비용 입력 (선택, 접이식 아코디언 제공)**:
  - `포장 부자재비`: 박스, 뽁뽁이, 테이프, 스티커 등 (건당 기본 500원 추천 프리셋)
  - `반품/교환 손실 충당금`: 판매가의 1%~3% 기본 권장 세팅 (반품 시 발생하는 왕복 배송비 및 상품 훼손 감가 반영)
  - `마케팅/광고비`:
    - 방식 A: 건당 투입 광고비 (원)
    - 방식 B: 목표 ROAS(%) 입력 시 건당 광고비 자동 산출
  - `기타 운영비`: CS 인건비, 사무실 고정비 배부액(선택)
- **과세 유형 설정**:
  - 일반과세자 (매출 부가세 10% - 매입 부가세 공제)
  - 간이과세자 (업종별 부가가치율 적용 or 세액감면 가이드)
  - 면세 사업자

#### [Feature 3] 실시간 마진 계산 엔진
입력값 변경 시 별도의 버튼 클릭 없이 **실시간(Live reactive)**으로 계산 결과 업데이트.
- **산출 항목**:
  1. **실제 정산금액 (정산 예정액)** = 총매출액 - 플랫폼 수수료
  2. **총 지출 비용 (원가 + 수수료 + 물류비 + 광고비 + 세금)**
  3. **최종 순이익 (Net Profit, 원)**
  4. **최종 마진율 (Net Margin Rate, %)** = `(순이익 / 총매출) * 100`
  5. **원가 대비 수익률 (ROI, %)** = `(순이익 / 투입원가) * 100`
  6. **손익분기 광고 ROAS (BEP ROAS)**: 적자가 나지 않기 위한 최저 광고 효율 계산

#### [Feature 4] 목표 마진 역산기 (Reverse Calculator)
- **사용 시나리오**: "내가 이 상품을 사입가 5,000원에 가져왔는데, 순마진 25%를 남기려면 쿠팡에서 얼마에 팔아야 하지?"
- **입력**:
  - 목표 마진율(%) 또는 목표 순이익(원) 선택 입력
  - 사입원가 및 제반 비용 입력
- **출력**:
  - **권장 판매가 (정가)**
  - **할인 판매 시 권장 표시가격 가이드**
  - 역산 판매가 적용 시의 상세 비용/수수료 내역 시뮬레이션

#### [Feature 5] 스마트 리스크 진단 & 알림 배지 (Health Check)
초보 셀러의 심리적 안정과 경각심을 위한 상태 진단 배지 제공:
- 🚨 **[위험 - 역마진 발생]** (순이익 < 0원):
  - 빨간색 경고창 팝업 및 흔들림(Shake) 효과
  - "판매할 때마다 건당 X,XXX원의 적자가 발생합니다! 판매가를 올리거나 광고비를 줄이세요."
- ⚠️ **[주의 - 초저마진 구간]** (마진율 0% ~ 10% 미만):
  - 노란색 경고: "반품 1~2건 발생 시 즉시 적자로 전환될 위험이 있습니다."
- ✅ **[안정 - 적정 마진]** (마진율 10% ~ 25%):
  - 초록색 배지: "이커머스 평균 수준의 안정적인 마진입니다."
- 🌟 **[우수 - 고마진 상품]** (마진율 25% 초과):
  - 블루 배지: "공격적인 광고 마케팅이 가능한 우수 마진 구조입니다."

#### [Feature 6] 데이터 시각화 & 편의 기능
- **비용 구성 도넛 차트**:
  - `매출액(100%) = 사입원가(%) + 플랫폼수수료(%) + 배송/포장비(%) + 광고비(%) + 세금(%) + 순이익(%)`
- **한 줄 요약 텍스트 복사**: 단체 대화방, 메모장에 붙여넣을 수 있는 텍스트 포맷 복사
- **결과 이미지 저장**: 카드 형태의 영수증 스타일 그래픽 저장 (SNS 공유 및 셀러 커뮤니티 질문용)
- **최근 계산 내역 보관**: 브라우저 로컬스토리지에 최근 10개 상품 계산 내역 저장 및 비교 기능

## 5. 핵심 계산 로직 및 수식 (Calculation Logic)

### 5.1 용어 정의
- $P_{sale}$: 상품 판매가
- $P_{ship\_customer}$: 고객 부담 배송비
- $R_{gross}$: 총매출액 = $P_{sale} + P_{ship\_customer}$
- $C_{product}$: 상품 매입/제조 원가
- $C_{ship\_actual}$: 실제 지출 배송비
- $C_{package}$: 포장 및 부자재비
- $C_{ad}$: 건당 광고비
- $C_{return\_reserve}$: 반품/파손 충당금 ($P_{sale} \times \text{충당율}$)
- $Fee_{platform}$: 플랫폼 판매 수수료
- $Fee_{ship}$: 플랫폼 배송비 수수료
- $Tax_{vat}$: 예상 납부 부가가치세

---

### 5.2 세부 수식 정의 (쿠팡 윙 일반과세자 기준 예시)

#### 1) 플랫폼 수수료 계산
$$\text{판매수수료} = P_{sale} \times \text{카테고리 수수료율} \times 1.1 \ (\text{부가세 } 10\% \text{ 포함})$$
$$\text{배송비 수수료} = P_{ship\_customer} \times 3.3\% \ (\text{부가세 포함})$$
$$Fee_{total} = \text{판매수수료} + \text{배송비 수수료}$$

#### 2) 정산 예정액
$$\text{정산액} = R_{gross} - Fee_{total}$$

#### 3) 부가가치세(VAT) 예상 납부액 (간이 추산)
- 매출 부가세 = $R_{gross} / 11$
- 매입 부가세 공제액 = $(C_{product} + C_{ship\_actual} + C_{package}) / 11$
- 플랫폼 수수료 부가세 매입세액공제 = $Fee_{total} / 11$
$$Tax_{vat} \approx \max(0, \text{매출 부가세} - \text{매입 부가세} - \text{수수료 부가세})$$

#### 4) 최종 순이익 (Net Profit)
$$\text{순이익} = R_{gross} - (C_{product} + C_{ship\_actual} + C_{package} + C_{ad} + C_{return\_reserve} + Fee_{total} + Tax_{vat})$$

#### 5) 순마진율 (Net Margin Rate)
$$\text{순마진율}(\%) = \left( \frac{\text{순이익}}{R_{gross}} \right) \times 100$$

#### 6) 손익분기 ROAS (BEP ROAS)
광고를 집행할 때 순이익이 0이 되는 최소 ROAS(Return on Ad Spend):
$$\text{광고 전 마진액}(M_{pre\_ad}) = \text{순이익} + C_{ad}$$
$$\text{BEP ROAS}(\%) = \left( \frac{P_{sale}}{M_{pre\_ad}} \right) \times 100$$
*(예: 마진액이 판매가의 25%라면, BEP ROAS는 400%. 즉 광고 효율이 400% 이상이어야 흑자)*

#### 7) 목표 마진 역산 판매가 공식
목표 마진율을 $M_{target}$ (예: 20% = 0.2), 유효 수수료율을 $F_{eff}$, 세금 및 변동비 비율을 고려하여 닫힌 형식(Closed-form) 공식 적용:
$$P_{target} \approx \frac{C_{product} + C_{ship\_net} + C_{package} + C_{ad}}{1 - (F_{eff} + M_{target} + \text{세금계수})}$$

### 6.2 UX 원칙
1. **Zero-Friction (무마찰)**: 회원가입, 로그인 없이 즉시 사용 가능
2. **Explainable Terminology (친절한 용어 툴팁)**:
   - ROAS, 매입세액공제, 정산주기, 수수료 부가세 별도 항목마다 `(?)` 아이콘 및 1줄 팝오버 설명 제공
3. **Smart Defaults (스마트 기본값)**:
   - 빈칸으로 두어도 실배송비(3,000원), 포장비(500원), 반품충당금(2%) 등 현실적인 이커머스 기본값 프리셋 제공
4. **Haptic & Visual Feedback**:
   - 역마진 발생 시 붉은색 테두리 점멸 및 경고음/진동(모바일) 옵션

## 7. 기술 스택 및 데이터 모델 제안

### 7.1 권장 기술 스택
- **Frontend**: Next.js 14 (App Router) 또는 Vite + React + TypeScript
- **Styling**: TailwindCSS + Shadcn/ui (모던하고 깔끔한 UI 컴포넌트)
- **Charts**: Chart.js or Recharts (가볍고 인터랙티브한 도넛/바 차트)
- **State Management**: Zustand or React Hook Form (실시간 반응형 렌더링 최적화)
- **Exporting**: `html2canvas` (영수증 카드 이미지 다운로드), `xlsx` or `csv` (내보내기)
- **Storage**: Browser LocalStorage (개인정보 저장 없는 브라우저 로컬 저장)

## 9. 기대 효과 및 결론

1. **초보 셀러 손실 방지**: 가격 책정 실수로 인한 역마진 리스크를 사전에 100% 방지.
2. **시간 절약**: 기존 엑셀 템플릿 검색 및 수식 오류 수정에 소요되던 시간을 단 1분으로 단축.
3. **지속 가능한 셀링 전략 수립**: BEP ROAS 및 부대비용을 사전에 파악하여 무리한 출혈 경쟁 및 광고 과소비 방지.
4. **플랫폼 락인(Lock-in)**: 정확하고 신뢰도 높은 계산 도구를 무료 제공함으로써, 향후 상세페이지 제작 솔루션 및 소싱 도구로의 자연스러운 사용자 유입 확보.
